How Avocet helps

Avocet keeps one calm page for everything a visitor needs to know, so nobody has to dig through menus to find the shared list.

  1. Open the pageEverything starts on a single screen with no sign-up.
  2. Read the listThe latest five items from the shared list appear in order.
  3. Check things offFinished items carry a tick so progress is clear at a glance.

Every item you see comes straight from the shared list, so what you read on this page is always the same as what the rest of the team sees.
